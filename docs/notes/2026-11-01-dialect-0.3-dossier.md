## Decisions taken without a ruling (for the council to check)

1. **Version string `0.3`**, file named `-draft`. Sub-versions: handles, regions, oracle-abi, tdl, effects, map, platform and driver move to 0.3; norm stays 0.2.8; markers, asm and corpus stay 0.2.
2. **Tags are not ids.** ISA ids are executor-chosen `i64` values that may be 0 or exceed 2^pw, so pointer-width tags stay and a table maps them (§6.1, §6.5). Tags are never reused.
3. **Table placement and image (S0 revision: `b-dialect-spec-d4s`, `b-dialect-spec-fa8`).** `__bennett_rt_qtab` is private device storage placed only after reserving the arena and interfaces of every oracle shape, by the single layout rule in §19.5. It uses the first fitting aligned gap at or above the heap end, or space after all regions. It moves no program or function address and is excluded from native text placement. It has a complete declared-size zero data image under ISA 0.9 §9.1–§9.2, not empty HEX. Exhaustion remains code 2; D29's default, including 2^40 bytes at pw=64, is unchanged.
4. **Interning.** A register entering through `QREG` gets its existing live tag, so tag equality stays identity (§6.3).
5. **Hoisting removed.** R uses `qreg.*` directly (§7.5(b)). The bounded static file stays optional in CC; nothing depends on it.
6. **`hostcall bennett.fault` removed.** CC uses `fault C` too, because K5 needs no host service (§11.5).
7. **A terminal R fault skips exit handlers and flush** (§19.2). This follows from K5; it is new text for lbq.
8. **Lowering report** replaces the blocker report and carries no verdict. Status 3 stays defined for a future blocker but is never used on 0.9.

## Weak points to attack

- **§8.4 and D34: full-domain shape dispatch.** The ruled construction names up to 2^64 reference objects, so no plugin can emit it in full. D34 lets a plugin report unfinished emission at build time and forbids a run-time `T-IFACE` for a valid shape. In practice a program with a truly unbounded oracle width will fail at build time, which is close to a narrowing even though it is honest. The real fix is an ISA request, `b-isa-spec-lpe` (width-parametric regions), filed with exact text. This is the one place where I doubt the ISA 0.9 text is enough; it is classed as efficiency because the ruling says so.
- **TDL-10 full-domain pad**: a top Co width asks for 2^64−1 wires, so on any real device it is code 2 at allocation. It is a defined outcome and the ruling's construction, but it is not a useful execution.
- **The qreg table is unexecuted.** `k1-table` will be the first run of §6.5's design.
- **Cross-run persistence.** §6.5 assumes device memory persists across runs of one loaded program. ISA §10's ownership text implies that but does not state it in so many words, and 0.2's cross-entry examples assume the same. `k1-table` runs in one entry only. Wording requested with exact text: `b-isa-spec-adg`.
- **Co budget fields**: §9.5 mints classical tuples only. A budget field that is Co inside a generation has no explicit rule in 0.2.12 or here, and K3 cannot mint from a location. Bead `b-dialect-spec-0nn`.
- R1 evidence: [`2026-11-01-r1-coherent-lifting.md`](2026-11-01-r1-coherent-lifting.md).

## S0 fixes for council: layout and data image

The receipt above predates these edits. Both S0 beads remain **OPEN** for council; object
admission below is not a claim that a compiler emits the table or that `k1-table` executes.

| Bead | Draft edits and determining reason |
|---|---|
| `b-dialect-spec-d4s` | §19.5 replaces the independent heap-end table placement with one ordered reservation: ordinary data/shadow, heap, arena, every oracle's interfaces, then the table in the least fitting 4096-aligned gap at/above the heap end. A table after the maximum end is admitted, and alignment gaps prevent false address-space exhaustion. Nonwrapping containment and per-oracle disjointness are required on the complete link. Private storage is excluded from native text placement, preserving A(F), program addresses, native ABI values and reference budgets; D15's summary now explicitly excludes the private table too. §3.1 attributes the private global to the plugin; §6.5 and TDL-4 cite this rule; §16.3 retains resolved bases and counts the private pre-entry in H/A_tab. §19.9 and D29 cite the resolved table size/layout, without changing defaults. §19.5 LQ-1–LQ-3/LQ-5 and §21.3 DB/DD/DM add combined-memory, all-shape, gap and default-size obligations; §25.1 and §25.4 distinguish these admission vectors from `k1-table` register execution. |
| `b-dialect-spec-fa8` | §19.5 replaces empty HEX/E4 with a complete B_tab-byte zero image, same-name data symbol and equal data-signature/global/image sizes, with hashes over the actual bytes and final layout. §6.5 defines the header/record/padding bytes and an initially zero issued-tag count (fresh tag c+1); allocation, interning and use checks now agree with that zero initial state. This also permits ISA id 0 without mistaking it for an unassigned record. §19.9 and D29 describe the actual image size; §19.5 LQ-4 and §21.3 DB/DD/DM require admission, zero-state, negative empty-image and reversal checks. §25.1/§25.4 cite the image requirement and evidence limit. Decision 3 and the 0na consumer row above reflect both corrected contracts. |

**Worked counterexamples.** LQ-1 has saved=[4096,4104), an empty heap at 8192,
and MEM_IN m0=[8192,8193). The old table [8192,12288) overlapped m0. The new
table [12288,16384) leaves every program address fixed. LQ-2 adds a 4096-byte shadow
at [4104,8200); the empty heap and 4096-byte arena start at 12288. The old table
overlapped the arena [12288,16384); the new table [16384,20480) is disjoint. LQ-3
adds a second oracle with an 8192-byte input [8192,16384), forcing the table to
[16384,20480) even when the one-byte oracle is emitted first. Each case uses a real
4096-byte zero image: 8 header bytes + 255×16 record bytes + 8 padding bytes. The
old empty HEX encoded 0 bytes, contradicting size 4096; LQ-4 emits 8192 hex digits,
hashes that full image and admits it. Default-size LQ-1 keeps B_tab=2^40 and ends
at 1099511640064 (H=41); pw=32 keeps B_tab=2^29 and ends at 536883200 (H=30).
No default limit, program class, or reference budget is reduced.

LQ-5 additionally uses pw=32, heap_end=8192 and four interface sizes 2^30, 2^30,
2^29, 2^28, ending at 4026531840. The unchanged 2^29-byte table fits in the first
alignment gap at [8192,536879104); appending it after all regions would exceed
2^32. This is why the central rule searches free gaps before declaring real layout
exhaustion. A 4096-byte full-image control checks admission with the same region bases.

**Reproducible focused admission check.** The following recipe creates temporary full ISA
objects only under the job TMPDIR. The independent cached ISA 0.9 interpreter computes
hashes, admits the controls, rejects both old encodings, reads the zero state and reverses
ordinary R writes. It does not execute qreg allocation or establish cross-entry persistence.
The large defaults are checked arithmetically; no terabyte image is allocated.
